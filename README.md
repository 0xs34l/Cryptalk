# Cryptalk

A Peer to peer secure messaging prototype that enables two users to exchange messages and verify their authenticity and integrity using digital signature.

This project demonstrates how digital signatures support sender authentication when the sender’s public key is trusted.

## Requirements
- **Rustup 1.29.1**
- **Cargo 1.99**

## Running
***Open one terminal for alice and another for bob***

**Terminal 1**
```cargo
cargo run --bin alice
```
**Terminal 2**
```cargo
cargo run --bin bob
```










***No LLM was used in the making of this prototype***
